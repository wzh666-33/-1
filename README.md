# mini-rcs-rms

这是一个用来学习的简易 AGV 仿真。调度和单车控制分开写。

- **RMS（调度系统）** 负责选哪台车、给出路径、做交通管制，并把路径交给 RCS。
- **RCS（控制系统）** 负责按收到的路径做底盘移动，并执行抬升、伸叉、放背篓，再上报位置、电量和故障。RCS 不决定去哪。

上层只说「从哪搬到哪」。给路径是 RMS 的事，执行是 RCS 的事。

正式产品里的路径规划是复杂算法。这个练习不写算法，RMS 使用一张写好的路线表，例如从堆塔到工作站走「空闲点 → 堆塔 → 工作站」。测试看的是路径有没有交给对的车、车有没有走完、两台车会不会抢同一个点。
